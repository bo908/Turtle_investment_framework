# 现金指标白盒总表 — 计算逻辑说明

> `/cash-metrics` 的口径定义与复现步骤。目标：每个数字都能对着财报原始行项手工复算。
> 计算公式沿用龟龟框架因子3（`scripts/tushare_modules/derived_metrics.py`），本表额外展示原始行项与算式。
> 金额单位：百万元（港股百万港元，美股百万美元）。原始数据 = Tushare 原始值 / 1,000,000。

---

## 数据来源标注约定

输出中每个原始行项后标注 `[§N·字段名]`，对应 data_pack 板块：

| 标注 | data_pack 板块 | Tushare 接口 |
|------|---------------|-------------|
| §3 | 合并利润表 | income |
| §4 | 合并资产负债表 | balancesheet |
| §5 | 现金流量表 | cashflow |
| §1 | 基本信息（市值/股本） | daily_basic |

年度口径：仅取财年末（A股12月末）报告期，最多近5年，降序。ΔX = 本年期末 − 上年期末。

**产出结构**：
- **参数速览（供填表）** 顺序：净利润(归母) → 广义现金(货币资金+交易性) → 狭义现金(货币资金) → 有息负债合计 → 总负债 → EBITDA → 真实现金流(最近一年AA) → AA_2y → AA_all。注意"现金"为**不减负债**的原始现金。
- **白盒明细** 输出顺序：§1 现金与负债 → §2 EBITDA → §3 真金白银AA → §4 回收期 → §5 承诺/预期。（本说明文档下方按主题编号，与输出顺序不完全一致。）

## 1. 现金与负债结构

### 有息负债（4分项，来自 §4 原始字段）

```
有息负债 = 短期借款 st_borr
         + 长期借款 lt_borr
         + 应付债券 bond_payable
         + 一年内到期非流动负债 non_cur_liab_due_1y
```
任一分项为空视为 0；4项全空则合计记为 —。

### 净现金（狭义/广义）

```
狭义净现金 = 货币资金 money_cap − 有息负债
广义净现金 = 货币资金 money_cap + 交易性金融资产 trad_asset − 有息负债
```

> **与 turtle 的差异**：turtle `derived_metrics.py` 的"广义净现金"实际只减了 money_cap，未加 trad_asset。本表按字面口径修正——广义确实加回交易性金融资产。

### 复现示例（伊利 600887 · 2025）

```
有息负债 = 45,630.63 + 472.48 + 0.00 + 4,414.71 = 50,517.81
狭义净现金 = 19,494.92 − 50,517.81 = −31,022.89
广义净现金 = 19,494.92 + 3.30 − 50,517.81 = −31,019.59
```

## 2. 真金白银现金流（真实可支配现金结余 AA）

口径：**真实现金收入 − 经营现金支出W − 全额capex**。资本投资一律视作开支（不区分维持/扩张），且**不加回投资收益**——这是最保守口径，等价于 turtle §17.5 的"基准结余"。

### 2A 真实现金收入（步骤1）

```
S = 营业收入 revenue [§3]
T = 应收账款变动 = accounts_receiv(本年末) − accounts_receiv(上年末)  [§4]
U = 合同负债变动 = contract_liab(本年末) − contract_liab(上年末)      [§4]

真实现金收入 = S − max(0, T) − max(0, −U)
```
保守规则：应收**增加**才扣（卖了没收到钱）；合同负债**减少**才扣（预收的钱花掉了）。应收减少、预收增加均不加回。

### 2B 经营现金支出 W（步骤4）

```
W1 供应商 = 营业成本 oper_cost [§3] + max(0, −ΔAP)
            ΔAP = acct_payable(本年末) − acct_payable(上年末) [§4]
W2 员工   = 支付职工现金 c_pay_to_staff [§5]
            ⚠️ 若为空 → 用利润表 SGA(sell_exp+admin_exp+rd_exp) 替代，标注 †，偏保守
W3 现金税 = 所得税 income_tax [§3] − (ΔDTA − ΔDTL)
            ΔDTA = defer_tax_assets 变动, ΔDTL = defer_tax_liab 变动 [§4]
W4 利息   = 财务费用 finance_exp [§3]

W = W1 + W2 + W3 + W4
```

### 2C 基准结余与 AA（步骤7）

```
当年基准结余 = 真实现金收入 − W − 资本开支 c_pay_acq_const_fiolta(全额) [§5]

AA_2y  = 近2年基准结余均值（默认基准）
AA_all = 全部年份均值
AA_excl= 剔除负值年份后均值
```

### 复现示例（伊利 600887 · 2025）

```
真实现金收入 = 115,636.23 − max(0, 109.02) − max(0, −(−1,508.55))
             = 115,636.23 − 109.02 − 1,508.55 = 114,018.66
W = 76,487.28 + 27,155.19 + 1,525.62 + (−690.85) = 104,477.24
基准结余 = 114,018.66 − 104,477.24 − 3,036.64 = 6,504.77
AA_2y = (6,504.77 + 5,628.60) / 2 = 6,066.69
```

## 3. 现金流回收期

```
回收期(年) = (市值 − 净现金) / AA = 企业价值EV / AA
```
- 市值来源 §1：A股 = total_mv(万元)×10000；港股 = total_market_cap(百万港元)×1e6；美股 = total_mv(原始美元)
- 净现金取最新财年；狭义/广义两口径 × AA_2y/AA_all → 2×2 矩阵
- 补充展示 §5 投资活动现金流净额 n_cashflow_inv_act 原值（仅供了解投资规模，不参与计算——capex 已在 AA 中全额扣除）

### 复现示例（伊利 600887，市值随行情变动）

```
回收期(狭义/AA_2y) = (市值 − (−31,022.89)) / 6,066.69
```

## 4. EBITDA 与估值倍数

**EBITDA 采用 Tushare `fina_indicator.ebitda`（与 turtle §17.8 同源，保证跨 skill 口径一致）**，但白盒展示其还原过程供对照财报复现。

### Tushare EBITDA 还原公式（已验证逐年闭合）

```
EBITDA = 利润总额 total_profit [§3]
       + 利息净额（利息费用 fin_exp_int_exp − 利息收入 fin_exp_int_inc）[§3]
       + 固定资产折旧 depr_fa_coga_dpba [§5]
       + 无形资产摊销 amort_intang_assets [§5]
       + 长期待摊费用摊销 lt_amort_deferred_exp [§5]
       + 使用权资产折旧 use_right_asset_dep [§5]
```

> **关键点**：
> - 用**利润总额**（不是营业利润），**利息净额**（不是财务费用净额）。
> - **使用权资产折旧 `use_right_asset_dep`** 是最易漏的一项——对重租赁公司（如分众的电梯点位）可占 EBITDA 30%+。turtle §17.8 标签写"营业利润+财务费用+D&A"但实际直接取 Tushare 字段，二者不符且不可复现；本表用完整还原式对齐 Tushare 值。
> - `use_right_asset_dep` / `fin_exp_int_exp` / `fin_exp_int_inc` 不在标准数据包字段内，引擎通过 `_fetch_ebitda_components()` 单独补取（A股专用；港股/美股无此拆分 → 还原降级，EBITDA 仍用 Tushare 值）。

### 估值倍数
```
EV = 市值 − 狭义净现金（与 turtle §17.8 对齐）
EV/EBITDA = EV / EBITDA
净负债/EBITDA = (有息负债 − 货币资金) / EBITDA   （负值 = 净现金）
```

### 复现示例（分众 002027 · 2025）
```
EBITDA = 3,889.73 + (110.28 − 116.88) + 192.35 + 10.32 + 6.39 + 2,520.13
       = 6,612.33   ✓（= Tushare fina_indicator.ebitda）
```

## 5. 承诺值 / 预期值（Phase 2）

Tushare 只有历史已实施值。承诺值/预期值需要年报里的分红政策——**但年报数据 business-analysis 已经拆好，优先复用，不要重复读 PDF/搜网。**

### 数据源优先级（降级链）

| 优先级 | 数据源 | 承诺/回购信息位置 |
|--------|--------|------------------|
| 1 首选 | `output/{code}_{company}/qualitative_report.md`（固定名） | 结构化字段 `distribution_signal:`（分红/回购意向摘要）、`capital_allocation_record:`（回购注销记录）；正文 D4/D5 股东回报规划 |
| 2 次选 | `{公司}_{代码}_分析报告.md` / `phase3_quantitative.md` | "步骤10 分配意愿"块：股息承诺、承诺场合、支付率M/N、注销型回购O、稀释净效果 |
| 3 兜底 | 年报 PDF / `/download-annual-report` / WebSearch | 利润分配政策章节、回购预案公告（仅当 1、2 均缺失时） |
| 4 降级 | 无 | §5 标"需人工填 + 建议先跑 /business-analysis {code}" |

> 首选路径的依据：`qualitative_report.md` 是 business-analysis 的标准机器可读产出，下游策略（龟龟见 `strategies/turtle/references/factor_interface.md`）都从它读参数。`distribution_signal` 字段（见 `shared/qualitative/references/output_schema.md` D5）定义即"从 MD&A 提取的分红/回购意向摘要"。

### 填写规则（区分承诺 vs 预期，不编造）

| 项目 | 说明 |
|------|------|
| 分红承诺（承诺值） | 年报明确承诺，如"三年分红率≥X%、每股≥Y元"；无明确承诺 → 标"无明确金额承诺（历史稳定高分红）" |
| 回购承诺（承诺值） | 回购预案金额上限/区间、价格上限 |
| 回购性质 | **注销型**=真股东回报；**激励型**=会再稀释，需剔除 |
| 预期值 | 历史支付率（§4）× AA/当前盈利 推算，标注"测算值非承诺" |

## 与 turtle 的关系

| 维度 | turtle 因子3 | 本表 |
|------|-------------|------|
| AA 计算公式 | 相同（derived_metrics.py） | **完全照搬** |
| V5 投资收益 | LLM 精算版会加回 | **不加回**（用 §17.5 基准口径） |
| 原始行项展示 | 只给变动值/合计 | **逐项展示 + 算式代入** |
| 可复现性 | 否 | **是**（对照财报逐格核对） |

交叉验证（伊利 600887）：有息负债 50,517.81、真实现金收入 114,018.66、W 104,477.24、AA_2y 6,066.69 均与 turtle data_pack §17 一致。
